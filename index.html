Fitur Unggulan

Dirancang untuk Ergonomi & Produktivitas

Flush Hardware Notch (Margin 0)

Menempel rapat di bawah panel atas KDE dengan lekukan telinga halus (concave ear curves ala MacBook & Dynamic Notch). Profil ultra-ramping (28px) memastikan tab editor VS Code dan browser Anda 100% tidak terhalang.

🎯 Click-Through Otomatis (Wayland Layer-Shell) 100% Tembus Klik

Lirik Karaoke LRCLIB (520px)

Ekspansi dinamis 520px Split-View. Mengambil lirik lagu tersinkronisasi otomatis dari API LRCLIB gratis dengan cache lokal, baris aktif menyala tebal, dan klik lirik untuk seek lagu.

🎤 Click-to-Seek Support Otomatis Spotify & Browser

Jadwal Sholat & Sun Arc (Day Trajectory)

Prayer times, right in the notch. Menampilkan kurva busur pergerakan matahari harian (Sun Arc Trajectory), penanda waktu sholat aktif menyala berpendar (glowing next prayer), hitung mundur lembut, serta heads-up hening 10 menit sebelum waktu sholat dan pop-up tenang saat waktu sholat tiba. Dihitung 100% lokal di PC Anda dengan metode resmi Kemenag RI tanpa memerlukan koneksi internet konstan.

🌙 Maghrib 17:52 • Subuh, Dzuhur, Ashar, Maghrib, Isya Kemenag RI Offline

Bluetooth TWS Manager & Peek

Integrasi BlueZ D-Bus. Kapsul pop-up 310x60px dengan animasi lepas-pasang TWS saat earbud dicolokkan atau dicabut, persentase baterai real-time, dan halaman manajemen perangkat bluetooth 1-klik sambung/putus.

🔋 85% Baterai TWS D-Bus org.bluez

Pusat Notifikasi & 1-Click Salin OTP

Mencegat notifikasi sistem ke Split-View inbox 40 riwayat terakhir dengan kategori pintar. Dilengkapi tombol 1-klik salin kode OTP langsung ke clipboard (wl-copy) serta toggle mode Jangan Ganggu (DND).

📋 1-Click OTP Copy 🔕 Mode Do Not Disturb

Hardware Telemetry & Processor TDP Monitor

Pemantauan langsung dari sensor kernel Linux: Processor Package Power / TDP (Watt PPT), suhu CPU (k10temp), GPU (amdgpu), dan SSD NVMe (°C), CPU Clock GHz, GPU Load & VRAM, deteksi proses terberat (Top Process), peringatan otomatis jika suhu melewati 85°C, serta sakelar 1-klik profil daya (🍃 Hemat, ⚖️ Seimbang, 🚀 Performa).

⚡ 24.5 W TDP • 58°C CPU • 49°C GPU powerprofilesctl Ready

Wayland File Shelf (Drag & Drop)

Seret file apa saja ke Dynamic Island bagian atas. Island otomatis membuka halaman Shelf dengan animasi pendaran "Island Gulp". Dilengkapi thumbnail gambar asli dan seret keluar kembali (Native Wayland QDrag) ke aplikasi lain.

📂 Native QDrag Wayland text/uri-list Drop

Pomodoro & Water Histogram

Timer Pomodoro dengan Circular Conic Ring bercahaya, transisi Focus 25m ↔ Break 5m + lonceng soft chime, serta grafik histogram minum air per jam dan pengingat istirahat mata 20-20-20.
